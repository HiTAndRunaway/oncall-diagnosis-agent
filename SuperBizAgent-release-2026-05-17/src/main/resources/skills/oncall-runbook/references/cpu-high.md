# CPU 高负载处置（参考资料）

配合 SKILL.md 使用，提供 CPU 高负载的详细排查步骤。

## 定位

1. `top` 按 CPU 排序，记录 top 5 进程与负载趋势（至少观察 5 分钟）。
2. 区分用户态/内核态/IO 等待：`top -1` 与 `vmstat 1 5`。
3. 检查是否存在突发流量（入口 QPS 对比基线）或定时任务叠加。

## 处置

- 单一进程异常：确认是否为业务预期（大促/批处理），否则重启或限流。
- 内核态高：排查系统调用异常、磁盘 IO 风暴。
- 负载持续超阈值：扩容（水平扩展）或拆分任务。

## 恢复确认

- CPU 使用率回落至 70% 以下并稳定 10 分钟。
- 记录开始时间、根因、处置动作、结束时间，更新值班记录。
